📖 Step-by-Step Architecture Guide: Google Sheets + Cloudflare + GitHub Pages (Full Setup)
▼ Click to Expand
  1. Part 1: Google Sheet Database Setup (5 Mins)
    • Create a new sheet at Google Sheets (sheets.new) and name it Suba Valli Vilas - CRM Database.
    • Click Extensions > Apps Script. Paste the code from google-apps-script.js (use the Copy button below).
    • In the toolbar, select setupSubaValliVilasSheets and click Run (creates all 8 sheets automatically).
    • Click Deploy > New deployment > Select Web app > Execute as: Me > Who has access: Anyone > Copy the /exec URL.
  2. Part 2: Cloudflare Worker Intermediary Setup (3 Mins)
    • Log in to Cloudflare Dashboard > Workers & Pages > Create application > Create Worker.
    • Name it suba-valli-vilas-crm-api. Click Deploy > Click Edit code.
    • Paste the code from cloudflare-worker.js and click Deploy.
    • In Worker Settings > Variables and Secrets > Add secret GSHEET_WEBHOOK_URL with your Google Apps Script URL.
    • Copy your Worker URL (e.g. https://suba-valli-vilas-crm-api..workers.dev) and paste it into the field above!
  3. Part 3: GitHub Pages UI Deployment (2 Mins)
    • Commit and push the project files to your GitHub repository.
    • In your GitHub repo, go to Settings > Pages > Source: Deploy from a branch (main / root).
    • Your CRM dashboard will be live at https://<user>.github.io/<repo>/ and the standalone Customer Feedback Portal at https://<user>.github.io/<repo>/feedback.html!
